adago-design · icons manager v1 · 实现契约
DOM · API · 存储 · 校验 · 验收
先设计后实现与 systems v2 同构MCP + HTTP

图标管理不是新开一套体系：它复用 design 包的图标注册表（icon_paths.go 内置 + custom-icons/*.json 自定义）， 把「注册表增删改 + 停用集合 + 元信息覆盖」做成设计包函数，再由 HTTP 管理端点与 MCP 工具共同调用。 画布弹层只是这套能力的界面；不引入第二份图标清单，也不改画布自身的构建期 icons.js 精灵。

01 · HTTP 管理端点/api/catalog/icons
方法 / 路径入参返回
GET /api/catalog/icons—{icons:[summary]} 含停用；summary = name/group/tags/builtin/disabled/overridden/svg
GET /api/catalog/icons/{name}—{icon:{...summary, body, svg, usage, viewBox}}
POST /api/catalog/icons{name, group, tags[], svg}201 {icon}；重名 409、非法 400
PUT /api/catalog/icons/{name}{group?, tags?, svg?}{icon}；内置只接受 group/tags，svg 传了即 400
POST /api/catalog/icons/{name}/state{disabled:bool}{icon}
POST /api/catalog/icons/{name}/reset—{icon}；仅内置：清覆盖 + 重新启用
DELETE /api/catalog/icons/{name}—204；内置 409，自定义删文件

错误统一为 {error:{code,message,hint?}}，code：unknown_icon / icon_builtin_protected / icon_duplicate / invalid_icon。

02 · MCPdesign_icons + 管理
工具变化
design_icons结果自动包含自定义图标；停用图标不出现在列表；format=inline 保留自定义 viewBox
design_icon_manage新增：action=list|create|update|disable|enable|remove|reset，参数 name/group/tags/svg/query

与 design_system_manage 同一套错误码与文本回执；create 后可直接用 design_icons 检索到。

03 · 存储<data>/
文件内容
custom-icons/<name>.json{name, group, tags[], svg, viewBox}；单文件即一个自定义图标
icon-settings.json{disabled:[name], overrides:{name:{group?,tags?}}}；内置图标的停用与元信息覆盖

写入均走 tmp 临时文件再 rename；启动时 LoadCustomIcons + LoadIconSettings， 失败只记日志不阻塞。自定义图标名不可改（名称即 #ds-ic-* 引用 ID）。

04 · 校验入库前
  • 名称：^[a-z0-9]+(-[a-z0-9]+)*$，1–48 字符；内置/自定义同名即冲突。
  • 分组：arrow / action / status / nav / media / data，留空默认 action。
  • SVG：可含 <svg viewBox> 外壳；只允许 path / circle / rect / line / polyline / polygon / ellipse / g / defs 渐变 / clipPath。
  • 禁止 script / foreignObject / text / image / style / use / a；禁止外链 href 与 url(http…)、on* 事件、<!DOCTYPE。
  • 正文 > 0 且 ≤ 64 KB；XML 必须可解析；未写明 viewBox 时默认 0 0 24 24。

节点用途

06 · 运行期接线design 包
函数 / 类型行为
Icon 增 Builtin、ViewBox内置初始化注册；自定义从文件读；sprite 用各自 viewBox
Icons() / SearchIcons() / IconCatalog()只返回启用图标（选择面）
AllIcons() / GetIconAny()管理面与渲染用；停用仍可取
IconSprite() / IconRef() / IconInline()使用全部已注册图标，避免模板引用因停用变空白
LoadCustomIcons(dir) / LoadIconSettings(dir)app.Start 里在体系之后加载
