原生壳是同一进程内的一层 mygo 窗口：窗口里只有一枚 WebView 指向已经在跑的画布页，标题条/状态条/托盘由 Go 直接画。HTTP API、MCP 工具契约、canvas.json 格式、页面 DOM 与类名全部不变；页面只新增一个 ?embed=native 分支。系统浏览器不是被删除，而是降级成 -browser 回退路径。

01 · 架构进程内分层，不是两个进程serve

关键取舍：不把画布 UI 重写为原生控件。页面已有完整交互（拖拽、检查模式、SSE、截图），重写等于重做产品；壳只补「桌面入口 + 状态 + 系统集成」。AutoOpen（截图超时自动拉起画布）在原生模式下改为聚焦既有窗口，不再弹浏览器。

03 · 标志矩阵一种界面，三条退路
命令 / 标志界面说明

04 · 页面契约embed=native 的全部差异
  • URL：/?embed=native，服务端原样返回同一份 index.html（不新增模板分支）。
  • 隐藏品牌与主题按钮：.tb-brand、#btn-theme；身份与主题归原生层，避免双份。
  • 只读回显：页面把 data-scope / data-scope-count / data-project-count / data-node-count 写到 <html>，壳每 2s 用 Page.Eval 取一次。
  • 标题：document.title = "<作用域> · adago-design"，浏览器模式下同样受益。
  • 不变：全部 id / 类名 / DOM 结构 / API / canvas.json 不动；浏览器模式像素级不变。
  • 机制：只有 .hidden 与 html[data-embed] 两条选择器，可被门禁静态断言。

06 · 生命周期服务先行，窗口随后
  • 1 解析配置，再取单实例锁（按 -data 分区）
  • 2 app.Start：端口探测、Store、MCP 装配
  • 3 实例被占则进故障卡（05/06 稿），不写数据
  • 4 建窗、建 WebView、DOMReady 后收起启动卡
  • 5 运行：Agent 写入经 SSE 即时反映
  • 6 关闭窗口 = 退进程：存窗口界、停服务

为什么先起服务：WebView 的 URL 必须指向已绑定端口；同时实例冲突可以在建窗前判定，避免出现「空窗口」。

07 · 验收机器门禁 + 真机冒烟
  • 门禁：GOWORK=off go build ./... && go vet ./... && go test ./... 全绿。
  • 契约测试：embed 分支选择器存在；dataset 键在 state.js 写入；-browser/-no-open/-window 解析矩阵；Deps.OpenCanvas 被调用一次且可回退。
  • 冒烟：原生窗口可打开、页面可交互、Agent 经 /mcp 新增节点即时出现、canvas_screenshot 回传 PNG、Ctrl+R 重载、F11 全屏、二次启动聚焦。
  • 不回归：MCP 工具清单与错误码、HTTP API、canvas.json v4 格式、既有 41 张稿可读。
08 · 风险与回退失败要能一眼退回
  • 缺少 WebView2 运行时：启动卡直说，并给「在浏览器打开」出口；不让进程静默死掉。
  • 纯 Go 构建：mygo 走 purego，CGO_ENABLED=0 仍产出单个 exe；构建脚本不改。
  • 无窗口 / CI：-no-open 与测试不创建窗口；go test 永不弹窗。
  • 回退：-browser 或 ADAGO_DESIGN_UI=browser 回到旧路径，不改数据。
