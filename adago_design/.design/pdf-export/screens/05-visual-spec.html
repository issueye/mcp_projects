纸张、字号、色板与分页
A4 · 210×297 / 297×210mm + pt打印优先

文稿是「印刷物」，不是界面：所有尺寸用 mm、字号用 pt、颜色用固定纸墨色板。 屏幕与纸面共用一套结构，屏幕只多一条打印提示；打印媒体下提示条隐藏、页面盒贴纸边。 界面主题（纸面 / 墨纸）不参与文稿配色，避免深色界面导出整页黑底。

01 · 纸张与方向PrintOrientation
项规则
横向A4 landscape：297×210mm，页面盒 296×209mm
纵向A4 portrait：210×297mm，页面盒 209×296mm
方向判定非 frame 稿件中「高 > 宽」记竖稿；竖稿 < 横稿 → 横向，否则纵向（平票取纵向）
页边距纸张 0；页内 padding 12/14mm（上下/左右）；页脚贴底
分页每页固定盒 + break-after: page；最后一张 auto，避免尾页空白

取舍：一份 PDF 只有一种纸张，混排项目必有一类稿被缩小；按多数决定，少数等比缩放、不裁切。浏览器打印时 @page 同向，原生 PrintToPDF 用 Go 侧选项。

02 · 预览与缩放只缩不放
方向可用框（px）缩放
横向1019 × 579min(1019/w, 579/h, 1)
纵向635 × 850min(635/w, 850/h, 1)

缩放只作用于 iframe 外层 .frame 的 transform，iframe 内部仍按原画板宽高排版：断点、字号关系与 1:1 结构不变。小于可用框的稿保持 100%，居中留白；逐稿页右上角显示「预览 97%」这类读数。

舞台底：画布色 #EDE8DC + 4mm 点阵（#C9C0AC），卡片白底 + 1.5mm 圆角 + 轻投影，与画布上的卡片同一视觉语言。

03 · 字号阶梯pt，打印尺度
用途字号说明
封面标题36 / 32 / 27 / 22pt按项目名长度收敛；行高 1.06，最多两行
页面标题20–21pt概览 / 索引页；行高 1.1
逐稿标题18pt行高 1.15；长标题换行不截断
正文 / 备注10.5–11pt行高 1.7；项目备注整段保留
表格 / 元信息8–9.5pt索引表 8.5pt，kicker 8pt 大写 + 字距
页脚8pt品牌 · 项目名 · 页码

字族固定 Inter → Noto Sans SC → 系统中文；节点 ID 与尺寸用等宽、tabular-nums，避免页码/尺寸在不同页里跳动。

04 · 纸墨色板与界面令牌同源
名值用在哪
纸面 #FBF8F1内页底
浅底 #FFFDF8面板 / 备注
画布 #EDE8DC预览舞台
墨 #16171A封面底 / 正文
次级字 #57544C说明 / 表格
辅助字 #6E6A60kicker / 页脚
线 #DCD5C6 / #C9C0AC分隔 / 页头

体系主色只用于 4mm 圆点，且先做 #RGB / #RRGGBB / #RRGGBBAA 形状校验；非法值退化为描边空心点，不进样式。

05 · 索引行数分页口径
方向每页索引行页数
横向14ceil(N / 14)
纵向18ceil(N / 18)
总页数2 + 索引页数 + N；空项目固定 3 页

索引列宽（纵向内容宽 181mm）：# 8 / 体系 30 / 类型 16 / 画板 24 / 尺寸 26 / 文稿页 12，标题自适应；偶数行浅底 rgba(242,237,226,.45)。

06 · 可读性打印优先的硬约束
  • 纸面文字对比度：墨 on 纸 16.2:1，次级 6.8:1，辅助 4.9:1。
  • 封面纸字 on 墨底 16.2:1；统计标签用 8pt + 字距，避免小字发虚。
  • 正文行高 ≥ 1.7；表格单元格不折行，超长用省略号（索引只做导航，详情在逐稿页）。
  • 页码、尺寸、ID 一律 tabular-nums / 等宽，跨页对齐。
  • 不依赖背景打印的设置：print-color-adjust: exact + PrintToPDF Background:true。
